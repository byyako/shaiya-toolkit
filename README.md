# Shaiya Toolkit

Tools for working with Shaiya's client data and patches, each with a command line and a window, for Windows, Linux and macOS.
Works on your own copy of the game: no game files are included or downloaded.

**Status: planning.** Nothing is released yet. Planned tools:

- `shaiya`: one command for archives (`data.sah`/`data.saf`), SData decrypt and encrypt, and patch build, apply and sign.
- SData episode schemas, so Item, Skill, Monster and NpcQuest files can be read beyond EP4.5.
- An SData editor that writes files back (decrypt, edit, re-encrypt with the right checksum).
- A packet-log decoder for the client's own log.

Each release will carry a prebuilt `.exe` per tool.
